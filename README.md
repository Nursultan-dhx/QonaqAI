# QonaqAI

Учебное веб-приложение для подготовки мероприятий в Астане. Этапы 01–04 включают аккаунты, мероприятия, подбор площадок, услуги, сохранённые DEMO-сметы и бронирование. Этап 05 добавляет серверного демо-помощника и редактируемые предложения через Facade и Builder. Этап 06 — демонстрационные Free/Pro, личный кабинет и уведомления об изменениях. Интерфейс на русском языке; бюджет указывается в тенге.

## Запуск

Нужны JDK 21+, Maven 3.9+ и Node.js с npm. Первый запуск требует интернет для загрузки зависимостей. Скрипт автоматически ищет JDK в `JAVA_HOME`, `.tools/jdk`, пользовательской папке `.jdks` и стандартных каталогах установки; Maven — в `PATH`, `.tools` и кэше Maven Wrapper. Приоритет имеет подходящий `JAVA_HOME`.

Из папки проекта выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

Также можно открыть `start.cmd`. Скрипт собирает React и запускает Java-сервер. Откройте [http://localhost:8080](http://localhost:8080). Остановка — `Ctrl+C`. Maven-зависимости сохраняются в `.tools/m2` внутри проекта. Если порт занят, остановите приложение, которое его использует, или задайте переменную окружения `PORT` перед запуском, например `$env:PORT=8081`.

Для сборки и проверки:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Эта команда собирает интерфейс и выполняет Maven `clean package` вместе с тестами. Результат находится в `backend/target`. При ручном запуске JAR задавайте рабочую папку `backend`, чтобы использовать ту же базу.

## Что проверить

1. Пройдите три шага интерактивного демо или перейдите к регистрации по кнопке «Пропустить демо».
2. Создайте аккаунт, затем выйдите и войдите с той же почтой и паролем.
3. Создайте мероприятие, сравните площадки и сохраните выбранный зал.
4. Измените параметры и проверьте подбор и уведомления.
5. Перезапустите сервер и войдите снова. Мероприятие должно остаться в списке.

В «Моих мероприятиях» кнопка «Настроить пакет и смету» открывает BASIC,
STANDARD и PREMIUM, дополнительные услуги и детализацию. Java рассчитывает
аренду, основу пакета, услуги и сравнение с сохранённым бюджетом. Все тарифы
явно обозначены как вымышленные DEMO-цены; фактические цены площадок в каталоге
остаются «по запросу». После расчёта нажмите «Сохранить смету»: пакет, часы и
снимок цен восстановятся после закрытия окна, обновления страницы и перезапуска
сервера (после повторного входа). Новый расчёт сам по себе не сохраняется.
Изменение гостей, даты, площадки или бюджета помечает старую смету устаревшей.
Версии конфигурации защищают сохранение из двух вкладок. Подробности:
[сохранение смет](docs/ESTIMATE_PERSISTENCE_IMPLEMENTATION.md).
Правила, API, примеры и проверки описаны в
[реализации Decorator](docs/DECORATOR_IMPLEMENTATION.md);
[Factory Method](docs/FACTORY_METHOD_IMPLEMENTATION.md) переиспользуется.

В том же окне после сохранения полной актуальной сметы выберите время в
`Asia/Almaty`, проверьте доступность и подтвердите бронь. Отмена освобождает
слот; история сохраняется после перезапуска. Подтверждённая бронь блокирует
несовместимые изменения мероприятия и пакета до отмены. Доступность и бронь
учебные, без связи с реальной площадкой. Подробнее:
[бронирование и блокировки](docs/BOOKING_IMPLEMENTATION.md).

Подробные входные данные и ожидаемые результаты приведены в [сценариях тестирования](docs/testing.md).

Демо ИИ использует подготовленный пример. На экране входа показан расчёт времени для одного сценария с условными значениями.

После входа помощник принимает произвольное описание, например: «Корпоратив на 80 гостей,
бюджет 2,5 млн, 20 декабря 2027, нужен простор». Серверный провайдер `DEMO_RULES`
выделяет параметры по правилам; внешняя языковая модель и API-ключ не требуются.
Нераспознанные поля остаются незаполненными. Проверьте подсказки, сохраните
мероприятие, выберите площадку, рассчитайте и сохраните смету. Кнопка
«Подготовить предложение» создаёт редактируемый черновик из этих данных.
Нажмите «Сохранить предложение», чтобы вернуться к нему через личный кабинет.
Изменение исходных данных помечает старый документ устаревшим.

В разделе «Тарифы» можно бесплатно переключить личный аккаунт между Free
(до 3 сохранённых предложений) и Pro (до 100, выгрузка TXT). Цены и подписка
демонстрационные, оплаты нет. Тариф и документы сохраняются в H2. Переход на
Free не удаляет документы. Общий демо-профиль позволяет подготовить черновик;
для сохранения предложения и выбора тарифа нужен личный аккаунт.
В «Личном кабинете» видны мероприятия, состояние смет, предложения, брони и
уведомления. Подробности API, паттернов и проверки:
[этапы 05 и 06](docs/MODULES_05_06.md).

Аккаунты, мероприятия, уведомления, конфигурации пакетов, снимки смет и брони сохраняются в H2. Вход открывает серверную сессию, а каждый аккаунт видит свои мероприятия. Через «Открыть общий демо-профиль» можно попробовать каталог без регистрации и открыть мероприятия из прежней демоверсии.

## Архитектура

- `frontend/` — React, Vite, оформление и взаимодействие пользователя.
- `backend/` — Spring Boot, HTTP API, бизнес-логика и H2.
- `backend/src/main/resources/catalog.json` — данные площадок; каталог можно расширять.
- `backend/src/main/resources/static/images/` — локальные фотографии площадок.
- `backend/data/` — файловая база H2. База, зависимости и результаты сборки не включаются в Git.
- `docs/sources.md` — официальные источники характеристик и фотографий.
- `docs/service-examples.json` — документальные примеры услуг; рабочие цены берутся только из backend service-rates.json, package-rates.json и отдельного demo-venue-rates.json.
- `docs/testing.md` — сценарии и результаты проверки; `docs/architecture.md` — паттерны и диаграммы.

Данные пользователя сохраняются в файловой H2 после перезапуска. Не запускайте одновременно несколько экземпляров приложения с одной базой.
Если H2 сообщает, что база доступна только на чтение, запускайте `start.cmd` из обычного сеанса Windows с правами записи в `backend/data`.

## Паттерны Нурсултана

**Strategy.** Два взаимозаменяемых способа подбора площадок. `ECONOMY` сначала использует опубликованную цену, если она есть; при неизвестной цене выбирает подходящую вместимость с меньшим запасом свободных мест. Такой запас — только ориентир при подборе, он не доказывает меньшую стоимость. `QUALITY` отдаёт приоритет простору по площади на гостя. Это не рейтинг качества обслуживания.

**Observer.** Собственная система наблюдателей получает событие изменения мероприятия, обновляет рекомендации и создаёт уведомление. Это явная реализация в коде проекта, которую можно показать отдельно от механизмов Spring.

Цена «по запросу» означает, что подтверждённая публичная цена отсутствует. Приложение не придумывает расценки или доступность площадок. Вместимость нужно читать вместе с указанным форматом рассадки; окончательные условия уточняются у площадки.

## Продолжение командной работы

Нурсултан отвечает за основу, площадки, Strategy и Observer. Бейбарыс подключает пакеты, услуги и смету, реализует Factory Method и Decorator. Этап 04 с бронированием реализован. Часть Дастана (05–06): серверный демо-помощник, предложения через Facade/Builder, демонстрационные тарифы и личный кабинет. Все участники проверяют общий сценарий, пишут тесты и описывают собственный вклад в отчёте.

Перед передачей кода проверьте запуск на компьютере следующего участника. Общие интерфейсы и API согласовывайте до изменения контрактов. Регулярно проверяйте, что сохранённые данные и функции предыдущего этапа работают.

## Примечания для разработки

В истории ранних этапов даты Git вручную устанавливались авторами; они не являются измерением времени выполнения разработки. Новые коммиты этапов 05–06 создаются по завершении частей работы с фактическим временем. Работа подготовлена с помощью ИИ. Использованные инструменты и внешние материалы нужно раскрыть в отчёте по правилам курса; каждый участник должен самостоятельно понимать, проверять и изменять свою реализацию.
