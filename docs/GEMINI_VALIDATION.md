# Проверка Gemini и новых тарифов

12 ноября 2026 года, локально на Windows.

- Production-сборка React/Vite: успешно.
- Полный Maven `test`: **275 тестов**, 0 ошибок, 0 падений, 0 пропущено.
- Из них 11 новых проверок диалога/шлюза Gemini и 264 существовавшие ранее.
- Живой доступ с предоставленным ключом к Google models API: HTTP 200.
- В интерфейсе 11 ноября Gemini отвечал на описание корпоратива, уточнял дату
  и предлагал три карточки с фото, вместимостью, площадью и пояснениями.
- 12 ноября в отдельном тестовом аккаунте проверена цепочка Pro: мероприятие →
  сохранённая смета → настоящее вступление от Gemini → сохранённое предложение →
  выгрузка TXT → личный кабинет. Канонический текст сметы сохранён без изменения.
- Дизайн тарифов проверен в Chrome на обычной ширине и 390 px. При ширине
  viewport 390 px ширина документа 375 px; горизонтального переполнения нет.
- Ключ отсутствует в доступных Git файлах, React dist и ресурсах/классах JAR.
  Локальная конфигурация `.tools/ai-local.properties` игнорируется Git.

Внешний API иногда обрывал TLS-соединение для Java/.NET. На этом компьютере
используется Node transport с включённой проверкой сертификатов и одной
повторной попыткой для сетевых сбоев/временных ошибок сервера Google.

Неизвестные цены показываются «по запросу». Ответ с карточками не подтверждает
соответствие бюджету без опубликованной цены. Бронирование и стоимость тарифов
по-прежнему учебные; реальная оплата не подключалась.

Публикация приложения и изменение настроек безопасности системы не выполнялись.
