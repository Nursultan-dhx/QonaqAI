# Gemini: диалог, карточки и тарифы

Помощник этапа 05 теперь использует Google Gemini через серверный
`POST /api/assistant/chat`. В запрос передаются история текущего диалога и
публичный каталог площадок. Чужие мероприятия, аккаунты и ключ не передаются
в контекст. Помощник задаёт по одному уточняющему вопросу, предлагает быстрые
ответы и до трёх карточек. Поля извлекаются из всей истории; перед сохранением
пользователь проверяет их в форме.

Карточки получают фотографии, вместимость, площадь и цену из серверного
каталога. Неизвестные ID и залы с недостаточной вместимостью отбрасываются.
Прошлые/неправильные даты и недопустимые числа не принимаются. Модель не создаёт
мероприятия, не сохраняет документы и не подтверждает брони.

## Настройка

Java-сервер принимает `GEMINI_API_KEY` и необязательный `GEMINI_MODEL`.
По умолчанию используется `gemini-3.5-flash-lite`. Локальная конфигурация может
находиться в `.tools/ai-local.properties`, которая исключена из Git:

```properties
qonaq.ai.api-key=YOUR_KEY
qonaq.ai.model=gemini-3.5-flash-lite
```

Файл загружается при запуске из `backend`. Ключ не включается в JAR, React,
HTTP-ответы или журналы. Не добавляйте его в исходники, README и команды запуска.
Приоритетная переменная `QONAQ_AI_API_KEY` может переопределить локальный файл.
Ключи с префиксом `AQ.` поддерживаются через заголовок `x-goog-api-key`.

Основной HTTP-клиент — Java. Для компьютеров, на которых его TLS-соединение
с Google не устанавливается, предусмотрен серверный Node.js 22+ транспорт:

```properties
qonaq.ai.transport=node
qonaq.ai.node-command=node
```

Можно указать абсолютный путь к `node.exe`. Ключ и тело запроса передаются
дочернему процессу через stdin, а не аргументы или временный файл. Адрес Google
зафиксирован в скрипте; проверка TLS-сертификатов включена. Приложение не
подменяет недоступный Gemini демонстрационным ответом. Ошибку можно повторить
или перейти к ручному вводу. `/api/assistant/status` показывает наличие настройки,
а не результат сетевой проверки. Старый `/api/assistant/suggest` оставлен
для совместимости и использует прежние правила; новый интерфейс его не вызывает.

## Реальные отличия тарифов

| Возможность | Free | Pro |
|---|---|---|
| Успешные ответы ИИ в день | 10 | 100 |
| Диалог и карточки площадок | Да | Да |
| Сохранённые предложения | 3 | 100 |
| Вступление к предложению с Gemini | — | Да |
| Выгрузка TXT | — | Да |

Учебная цена Pro — 4 990 ₸ в месяц. Переключение бесплатное; платёжного сервиса
и списаний нет. Общий демо-профиль имеет общий дневной лимит Free; собственные
лимиты, сохранение предложений и выбор тарифа доступны личному аккаунту.

`AiQuota` хранит счётчик в H2, обновляет его в полночь `Asia/Almaty`, возвращает
лимит при ошибке провайдера. Проверки выполняются сервером. Синхронизация рассчитана
на один локальный Java-сервер; для нескольких экземпляров нужна распределённая
блокировка/атомарный счётчик. Переход между тарифами не сбрасывает расход.

`POST /api/events/{id}/proposal-ai-draft` доступен владельцу на Pro и только
с актуальной сохранённой сметой. Gemini составляет вступление, а канонический
документ Builder с числами и условиями добавляется без изменения. Черновик
редактируется и сохраняется пользователем через существующий Facade.

## Проверки

`AssistantChatIntegrationTest`: сессия, история, реальные ID каталога,
вместимость, даты/числа, дневные лимиты, возврат лимита при ошибке, проверка Pro
и сохранение исходной сметы. `GeminiClientTest`: JSON, исключение thinking-частей,
обработка квоты/ошибок и отсутствие ключа в клиентской диагностике.

Моки в автоматических тестах не являются подтверждением ответа внешнего API.
Живую проверку Gemini фиксируйте отдельно от сборки и тестов.
