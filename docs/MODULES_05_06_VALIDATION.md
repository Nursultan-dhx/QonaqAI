Перезапуск проверяет `scripts/check-planning-restart.py`. Он создаёт отдельную
временную файловую H2 в `.tools`, запускает JAR и удаляет только свою тестовую
папку. Для принудительного завершения процесса на Windows используется
`WRITE_DELAY=0` у тестовой БД, чтобы каждый commit был записан до остановки.
Это настройка изолированной проверки, обычная база приложения не изменяется.

Запуск после сборки:

```powershell
python scripts/check-planning-restart.py
# С проверкой обновления старой базы:
python scripts/check-planning-restart.py --baseline C:/path/to/module04.jar
```

Браузерная проверка: `scripts/check-planning-ui.mjs`. Нужны Playwright, Chrome
и отдельный запущенный экземпляр приложения. Задайте `QONAQ_UI_TEST_BASE_URL`.
Если Playwright установлен вне дерева проекта, задайте `QONAQ_PLAYWRIGHT_MODULE`
путём к его `index.mjs`. Результаты и снимки по умолчанию пишутся в
`.tools/planning-ui`; путь можно изменить через `QONAQ_UI_ARTIFACT_DIR`.
Проверка создаёт только тестовый аккаунт в указанном приложении.
